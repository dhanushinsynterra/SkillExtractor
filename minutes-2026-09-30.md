# Minutes of meeting
_9/30/2026, 9:43:22 PM_

## Ideas
- **Voice-Based AI Friend for Candidate Assessment** — Create a friendly, voice-based AI assistant that assesses a candidate's domain and skill depth through natural conversation, rather than a formal interview structure.
- **Psychological Strategy for Candidate Assessment** — Use active empathy and lightweight ice-breakers to build rapport and reduce communication anxiety, encouraging honest and confident responses from candidates.
- **Collaborative Problem-Solving Candidate Assessment** — Use a collaborative problem-solving exercise with a persona to assess candidate skills without creating confrontational test pressure, maintaining a supportive and friendly tone.
- **Stealth Debugging Candidate Assessment** — The AI presents a broken code snippet or architectural bug and asks the candidate to explain the fix, revealing their problem-solving logic and technical knowledge in real-time.
- **Voice-Controlled Code Correction Interface** — Candidates fix a broken code card by issuing precise verbal instructions line by line. The AI acts strictly on these instructions without auto-correcting or auto-completing, testing precise communication and technical accuracy.
- **Visual Design for Candidate Assessment Interface** — Use a calming palette of soft blues and greens, a minimalist layout, and clear typography to reduce candidate anxiety and create a homely, professional environment.
- **AI Real-Time Skill-Tracking System** — Implement a dynamic skill-tracking system, such as a knowledge graph, within the AI to monitor competencies in real-time and ensure smart, non-redundant follow-up questions.
- **Implicit Skill Validation Through Contextual Questioning** — Design the AI to use contextual, follow-up questions about related technologies and tools based on the candidate's core domain, enabling implicit validation of supplementary skills and tools during the conversation.
- **Acoustic Emotion Analysis for Nervousness Detection** — Integrate acoustic emotion analysis to monitor changes in speech rate, tone, and pitch, enabling the AI to detect candidate nervousness and respond empathetically or provide reassurance.
- **Calm UI/UX Design for AI Agent Interaction** — Design the UI with a clean, minimalist layout, ample whitespace, and soft, rounded elements to create a calm, friendly environment, using a subtle glow around the microphone indicator to show active listening.

## Requirements
- **Assessment Report Audience** — The assessment report will be reviewed by the manager, HR, and the technical team, so the format should cater to their needs.
- **Candidate Onboarding Flow** — The candidate sees a welcome screen explaining the friendly, voice-based assessment, followed by a hardware check to verify the microphone and camera functionality.
- **AI Introduction and Ice-Breaker Step** — After the hardware check, the AI introduces itself, uses a lightweight ice-breaker to build rapport, and begins the collaborative problem-solving exercise to assess the candidate.

## Decisions
- **Low-Latency Voice Communication Architecture** — Use WebSockets and Gemini Live models to achieve low-latency, real-time voice interaction during the candidate assessment.
- **Phone Usage Detection and Warning Protocol** — Use webcam computer vision for gaze tracking and object detection to identify phone usage, with the AI issuing a subtle warning first and reserving session termination for repeated violations.
- **Voice Verification and Speaker Diarization** — Implement speaker diarization or voice biometrics to distinguish between different speakers and flag sudden changes in voice characteristics to prevent other people from answering for the candidate.
- **Adaptive Gaze-Tracking Policy** — Implement adaptive threshold gaze tracking to allow for brief natural glances away from the screen while flagging prolonged focus elsewhere to maintain high security standards.
- **Express.js for Backend Architecture** — Use Express.js for the lightweight backend to handle token management, session orchestration, and secure communication routing with minimal overhead.
- **React with TypeScript for Frontend Architecture** — Use React with TypeScript for the frontend to manage real-time voice interactions efficiently and provide robust support for multimedia APIs.
- **Real-Time Audio and Text Streaming Architecture** — Utilize WebSockets to stream both text and audio packets using the Gemini Live model, providing real-time audio and a visual text transcription fallback for accessibility.
- **Backend Session Persistence Strategy** — Maintain session history and conversation context in the application backend to enable seamless reconnection and session resumption with the Gemini Live model.

## Actions
- **AI Reassurance for Nervous Candidates** — Instruct the AI to respond empathetically and provide reassurance or calming statements when acoustic emotion analysis detects candidate nervousness or anxiety.
